# Pride Pathways
This is meant to be a web and mobile directory to help LGBTQI+ individuals in access services in NYC and surrounding areas.

Although NYC is generally considered an accepting city, LGBTQI+ people have few services designed for them, and limited access to the ones that exist. LGBTQ+ individuals make up 14-15% of homeless youth [CUNY](https://sw4youth.commons.gc.cuny.edu/statistics/), and 17% of homeless adults [Williams Institute](https://williamsinstitute.law.ucla.edu/publications/lgbt-homelessness-us/). 

Homelessness already creates many barriers to services, and queer identity adds concerns about safety and acceptance. Tools made for the community, by the community, can build trust and expand access.
